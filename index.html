🧬 序列比对

基于动态规划的 Needleman-Wunsch 全局比对 与 Smith-Waterman 局部比对。支持 DNA / RNA / 蛋白质序列，粘贴或上传 FASTA / 纯文本，自动去除 FASTA 头行并识别序列类型。

  1. 从 rcsb.org 下载受体结构 receptor.pdb（可先在 PyMOL 中去除水分子与共晶配体）。
    2. 
          
  2. 准备配体文件 ligand.sdf / ligand.pdb（确保氢原子完整、质子化状态正确）。
    3. 
          
  3. 在下方"3D 查看"中载入受体与配体，检查结合口袋位置，读出口袋中心坐标（或用 PyMOL：get_center）。
    4. 
          
  4. 用下方"对接参数生成器"生成 receptor.pdbqt / ligand.pdbqt 转换命令与 config.txt。
    5. 
          
  5. 在 WSL / Windows 中执行转换命令与 vina --config config.txt 开始对接。
    6. 
          
  6. 对接完成后，把输出的 *_out.pdbqt 拖入下方"对接结果查看"，按亲和力排序查看各构象与受体残基相互作用。
